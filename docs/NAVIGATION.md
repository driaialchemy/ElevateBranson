# Navigation

Five bottom tabs. From Home, every feature is one or two taps. A tab is one tap. A page inside that tab is a second tap. Home also has shortcut buttons for the pages people need most often.

| Tab | What it opens |
| --- | --- |
| Home | Shortcuts, newest newsletter, next event |
| Programs | Program list, plus Thrift Store, Elevate Coffee, Playground, and Tiny House |
| Events | Upcoming events |
| Get Involved | Volunteer, Tour, Prayer, Give, Merch |
| More | About, Find Us, Resources, Social, Website, Newsletter, Privacy |

About also links to Find Us and Newsletter.
